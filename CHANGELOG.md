# Changelog

## 0.1.0 - release candidate

- Deterministic Controlled English CE-1 compilation to HRM.
- Vocabulary aliases, plurals, and verb forms.
- Source evidence, diagnostics, strict/partial compilation, and inheritance-cycle validation.
- Hardened CLI file limits and protected output writes.
- ESM core and CLI bundles with external-consumer smoke coverage.

This is a release candidate. Full UML diagram generation is not included.

## 0.2.0 - development milestone

- Added deterministic Use Case DIR contracts and HRM mapping.
- Added semantic validation, stable layout, secure SVG rendering, and headless generation API.
- Added `generate usecase` CLI support for SVG and DIR JSON output.

Only Use Case Diagrams are included in this milestone.
